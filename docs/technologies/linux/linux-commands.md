| Command                              | Description                                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| ps a                                 | Processes attached to the current terminal.                                                                              |
| ps x                                 | Your user processes.                                                                                                     |
| ps ax                                | All processes on the system.                                                                                             |
| ps ax -o user, pid, comm --sort=user | Shows 3 columns and sorts by user.                                                                                       |
|                                      |                                                                                                                          |
