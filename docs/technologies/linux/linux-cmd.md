## Network Commands

### IP Command

The purpose of the ip command is to show or manipulate the network
devices/interfaces on your local machine. You can view and modify information
related to IPv4; alter default route tables; ARP tables; etc.

| Command                        | Description                                   |
| ------------------------------ | --------------------------------------------- |
| ip a                           | Show IP info for all interfaces.              |
| ip a show dev [interface_name] | Show specific IP info for an interface.       |
| ip r                           | Display the default route.                    |
| ip l                           | Display MAC info for link interfaces.         |
| ip l show dev [interface_name] | Display MAC info for specific link interface. |
| ip n                           | Show ARP table.                               |
